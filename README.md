# atividade-logica

Este programa serve para analisar notas de alunos e informar quantas foram aprovadas e quantas foram reprovadas.
O programa usa variáveis para guardar a quantidade de notas aprovadas e reprovadas.
Ele também usa um laço de repetição, que faz o programa analisar 5 notas, uma de cada vez.
Por fim, usa uma condicional para verificar cada nota: se ela for maior ou igual a 6, é considerada aprovada; se for menor que 6, é considerada reprovada.
O programa foi adaptado para o Streamlit, que transforma o código Python em uma página interativa que pode ser usada pelo navegador.
